\load[turtle]

Turtle graphics can be embedded directly in normal \OpTeX\ text.\par
The drawing starts at the current \TeX\ position and uses the current
pen state.\par

\def\square#1 {\repeat 4 {\forward #1 \right 90 }}
\def\flower#1 #2 {\repeat 36 {\right #1 \square #2 }}
\def\text#1{%
   \puttext \x pt \y pt {#1}%
}
\def\rotatedtext#1{%
   \text{\rotbox{\angle-90}{#1}}%
}


\begturtle
\square 45
\endturtle

The document continues normally after the drawing.
\begturtle
\flower 15 20
\endturtle



\begturtle
\pensize 0.5
\right 90 \rotatedtext{A}\forward 100
\Red
\right 90 \rotatedtext{B}\forward 100
\Green
\left 90 \rotatedtext{C}\forward 200
\Blue
\left 45 \rotatedtext{D}\forward 50
\endturtle
